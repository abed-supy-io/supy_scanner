FAQ

What teams ask before switching

Does any scan data leave the device?

No. Barcode and document recognition run entirely on-device via Apple Vision and Google ML Kit. There are no network calls in the scanning path.

How hard is it to migrate off our current SDK?

The compat shim mirrors the existing call sites exactly — same widget props and method signatures — so the cutover is an import-only change with no behavior difference for end users.

Which platforms are supported?

iOS 16+ (AVFoundation + Vision) and Android 21+ (CameraX + ML Kit), through a single Flutter 3.29 / Dart 3.7 package.

Which barcode formats can it read?

13 symbologies: QR, EAN-13, EAN-8, UPC-A, UPC-E, Code 39, Code 93, Code 128, ITF, PDF417, Data Matrix, Aztec and Codabar. Enable any subset, or all at once.

How does pricing work?

A simple flat license per app — no per-scan metering. Built on the native vision frameworks (no third-party SDK royalties), so every plan covers unlimited scans; tiers differ by the number of activated devices (seats). Pick a tier above, or talk to us for enterprise (unmetered seats).
