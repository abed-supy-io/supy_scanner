# DEPENDENCIES.md — supy_scanner

Dependency audit for the v1.0.x line. Tracks H3-07.

Last audited: **2026-06-14** (commit on `main`).

## How this document is used

Every dep that lands in a published artifact is listed here with:

- **Version** — pinned, exact.
- **Origin** — registry + license.
- **Purpose** — why it's in the graph.
- **Network behaviour** — does it phone home at build, install, or run time?
- **Update cadence** — when do we revisit?

If a dep can't be described in those five columns, it shouldn't ship.

## 4. Native C++ core (`native/`)

The v1.1 native core (`SupyNativeCore`) lives outside `android/` and `ios/` and is compiled by each platform from the same sources:

- Android: CMake driven by `android/build.gradle` `externalNativeBuild`, NDK `26.1.10909125`.
- iOS: compiled in-pod via `SupyNativeCoreImpl.mm` `#include`ing the `.cpp` files; CMake is **not** used on iOS to avoid CocoaPods' fragile parent-directory source handling.

No third-party C++ libs are vendored in v1.0.x. v1.1 vendors two C/C++ deps **behind independent build flags** (default OFF; not in the v1.0.x audit surface yet):

| Library | Pinned tag | License | Build flag | Purpose | Source |
|---|---|---|---|---|---|
| zxing-cpp | v2.2.1 | Apache-2.0 | `SUPY_WITH_ZXING_CPP` | 1D + 2D barcode decode (`supy_core_decode`). | https://github.com/zxing-cpp/zxing-cpp |
| libdmtx | v0.7.7 | BSD-2-Clause | `SUPY_WITH_LIBDMTX` | Data Matrix **locator only** — corners feed back into zxing-cpp on the ROI crop (`supy_core_locate_datamatrix`). | https://github.com/dmtx/libdmtx |

## 6. Network footprint summary

| Surface | Network at runtime? |
|---|---|
| Dart library | None. No `http` / `dio` / socket usage. |
| Android plugin code | None directly. GMS Document Scanner triggers an OS-mediated model fetch via Play Services (one-time per device install). |
| iOS plugin code | None. All frameworks on-device. |
| Build-time | Gradle / CocoaPods / pub fetch deps from their respective registries; standard practice. |

A repo-wide `grep -nrE "http(s)?://|URLSession|HttpURLConnection|OkHttp"` in `lib/`, `android/src/`, and `ios/Classes/` returns no matches that issue network traffic from this library. (Confirmed at audit time; re-run this check whenever a dep is added — see `docs/SECURITY.md` §12.)

## 7. Update cadence

- **Pinned exact versions** for every native dep; no version ranges. A bump is a PR, not a `pub upgrade`.
- **Audit cadence:** at minimum once per minor release; mandatory before each tagged release per `docs/RELEASE.md` (pending H4-04).
- **Trigger to re-run earlier:**
  - A native dep ships a security advisory.
  - A new dep is added to either Gradle or CocoaPods.
  - `FLUTTER_VERSION` is bumped.
